# Layout Camera

**Layout Camera 1.20.7** для Minecraft Java 26.3, Fabric Loader 0.20.1 и Java 25. Мод работает в одиночном мире и в мире, открытом по LAN.

## Команды

| Команда | Что делает |
| --- | --- |
| `/givetool` | Выдаёт палку «Выделитель зон». В обычном режиме **Shift** переключает тип зоны. Нажми **ЛКМ** на двух блоках, чтобы выбрать углы. Чтобы удалить зону, выбери её тип и нажми **ЛКМ** внутри неё, когда первый угол ещё не выбран. |
| `/giveroutetool` | Выдаёт хозяину палку «Разметчик маршрута». В обычном режиме **ЛКМ** добавляет точку, **ПКМ** отменяет последнюю точку. |
| `/givepet <id>` | Выдаёт предмет призыва моба из `mobs.json`. Например, `/givepet chicken_bab` или `/givepet layoutcamera:chicken_bab`. Нажми предметом **ПКМ** по блоку для обычного призыва. |
| `/startspawn` | Запускает доступные красные зоны в пределах 10 блоков от игрока. Внутри уровня применяются настройки его зон, снаружи — общий `spawn.json` для прежних зон. |
| `/createlevelnpc` | Создаёт в текущей точке NPC «Карта уровней». Хозяин открывает карту ПКМ по NPC. NPC сохраняется вместе с миром. |

Команды работают в одиночном мире и по LAN. Хозяин размечает зоны и запускает волны. Гости могут призвать сохранённый уровень, убрать свою копию и получить предмет моба внутри неё. [Гайд по созданию уровня](#гайд-по-созданию-уровня)

## Зоны и планирование

| Код в конфиге | Цвет | Название |
| --- | --- | --- |
| `green` | Зелёный | Нижняя зона |
| `blue` | Синий | Верхняя зона |
| `red` | Красный | Зона спавна |
| `white` | Белый | Зона финиша |

Нажми **J**, чтобы войти в режим планирования или выйти из него. Чтобы разместить моба, перетащи его предмет призыва из хотбара на свободную точку разрешённой зоны. Во время перетаскивания модель возле курсора поворачивается с шагом 90° вслед за стрелкой размещения. Точка появляется на горизонтальной зоне размером 2×2 блока и высотой в один блок. Для встроенной курицы также подходят обычное яйцо и яйцо призыва курицы. Чтобы удалить размещённого моба, выбери его **ПКМ** и нажми появившуюся кнопку удаления.

Редактируй границы зон в исходной области вне режима планирования. Нажми **J** в пределах 20 блоков от своей призванной копии, чтобы осмотреть её с уровня глаз под наклоном 60°. В режиме планирования красная зона спавна и белая зона финиша видны сразу, когда попадают в кадр. Блоки перекрывают скрытые части зон и маркеры размещения. Синие и зелёные зоны можно осмотреть курсором. При перетаскивании предмета подсвечиваются подходящие свободные точки. Если точка занята, выбери её моба **ПКМ** и нажми кнопку удаления, чтобы освободить место. Модели расставленных мобов видны в загруженных чанках с обеих сторон границы уровня.

Если расставленный защитник Верхней или Нижней зоны погиб во время волны, его точка освобождается и остаётся свободной при следующем `/startspawn`. В исходной расстановке гибель сохраняется после перезахода в мир. В призванной копии гибель действует до удаления или замены копии. Выжившие защитники возвращаются в расстановку. На освободившуюся точку можно вручную поставить нового моба.

## Гайд по созданию уровня

### Создание и запуск на примере `arena`

1. Построй площадку и введи `/givetool`, чтобы получить палку «Выделитель зон». Если включён режим планирования, выйди из него клавишей **J**.
2. Введи `/layoutlevel create arena`. Отметь **ЛКМ** два противоположных угла всего объёма, который хочешь сохранить. Оба угловых блока входят в выделение. Для имени подходят строчные латинские буквы, цифры, дефис и подчёркивание, до 32 символов.
3. Переключай цвет палки клавишей **Shift** и выделяй по два угла каждой зоны внутри объёма. Для волны нужны красная зона спавна и белая зона финиша. Для защитников добавь синие или зелёные площадки размером 2×2 блока и высотой в один блок.
4. При необходимости введи `/layoutlevel zones arena` и нажми на ID красной зоны, чтобы скопировать его. Задай параметры командой ниже, подставив скопированный ID вместо `<id_зоны>`.

   ```text
   /layoutlevel zone arena <id_зоны> {"order":["minecraft:zombie","minecraft:skeleton"],"interval_ticks":20,"total_enemies":6}
   ```

5. Если в каждой копии нужны защитники, расставь их в исходной области. Получи предмет через `/givepet chicken_bab` или укажи другой ID из `mobs.json`, включи планирование клавишей **J** и перетащи предмет на свободную площадку разрешённого цвета.
6. Введи `/createstage arena`. При первом вызове блоки, зоны и расстановка сохранятся в `Stage/arena`. Мод создаст временную копию у верхнего предела строительства, восстановит защитников на их точках и перенесёт туда тебя. Внутри копии можно менять расстановку на время игры.
7. Встань внутри копии в пределах 10 блоков от красной зоны и введи `/startspawn`. Мобы пойдут к подходящему белому финишу этого уровня.
8. Чтобы завершить игру, введи `/removestagecopy arena`. Копия исчезнет, а ты вернёшься в исходную точку и измерение. Хозяин может убрать все активные копии уровня через `/removestage arena`. Сохранение и настройки остаются в `Stage/arena`.

### Все команды для уровней

| Команда | Действие |
| --- | --- |
| `/givetool` | Выдаёт палку для разметки границы и зон. |
| `/layoutlevel create <имя>` | Начинает разметку исходной области по двум углам. |
| `/layoutlevel cancel` | Отменяет текущую разметку внешней границы. |
| `/layoutlevel` или `/layoutlevel list` | Показывает исходные области текущего измерения и путь к их JSON-файлу. |
| `/layoutlevel zones <имя>` | Показывает ID, координаты и настройки зон исходной области. Нажатие на ID копирует его. |
| `/layoutlevel routeclear <имя> <id_зоны>` | Удаляет ручной маршрут красной зоны. При следующем запуске для неё строится автоматический путь. |
| `/layoutlevel zone <имя> <id_зоны> <JSON>` | Заменяет настройки одной зоны исходной области. Пустой объект `{}` возвращает настройки по умолчанию. |
| `/layoutlevel reload` | Перечитывает JSON исходных областей текущего измерения. |
| `/createstage <имя>` | Создаёт временную копию по имени и переносит туда игрока. Хозяин может первым вызовом сохранить исходную область. Гости по LAN могут вызывать готовые сохранения. |
| `/givepet <id>` | Выдаёт предмет моба для расстановки в режиме планирования. Гость по LAN может использовать команду внутри своей призванной копии. |
| `/startspawn` | Запускает доступные красные зоны текущего уровня в пределах 10 блоков от игрока. |
| `/removestagecopy <имя>` | Убирает собственную временную копию по имени и возвращает игрока в точку входа. Уровень можно снова призвать из `Stage`. |
| `/removestage <имя>` | Убирает временные копии этого уровня и возвращает игроков в их точки входа. Сохранение, настройки и исходная разметка остаются. |
| `/layoutlevel delete <имя>` | Убирает временные копии и удаляет разметку исходной области в этом мире. Сохранение и настройки остаются в `Stage/<имя>`. |

### Настройки зон

Границы исходных областей в одном измерении могут соприкасаться. Оба угла каждой зоны должны находиться внутри одной исходной области. Прежние зоны и расстановки сохраняются отдельно.

Во всех зонах `enabled` по умолчанию равно `true`. При `false` красная зона не запускается, белая не используется для новых маршрутов и удаления мобов по контакту, а в синей и зелёной зоне нельзя расставлять новых мобов или запускать её защитников в бой. Сохранённые расстановки доступны хозяину для редактирования.

В Верхней и Нижней зонах `allowed_mobs` задаёт список ID из `mobs.json`, например `["layoutcamera:chicken_bab"]`. Без поля доступны все мобы, подходящие по `can_place` и `placement_zone`. Пустой список закрывает размещение и участие защитников этой зоны в новых волнах.

У каждой красной зоны свой `order`, `interval_ticks`, `total_enemies`, `finish_search_radius` и `attack_zones`. Значения по умолчанию для зоны уровня — один тип `minecraft:zombie`, интервал 40 тиков, 10 мобов, поиск финиша до 50 блоков и все четыре цвета целей. При запуске зона ищет доступный финиш своего уровня. Если рядом несколько подходящих зон, каждая выпускает свой набор мобов со своим интервалом и лимитом. Расстояние проверяется от ног игрока до ближайшей точки зоны по трём осям, включая границу в 10 блоков. Порог проверяется только при вводе команды.

Файл `*.levels.json` хранится на компьютере хозяина в `config/layout-camera/zones` внутри папки игры, отдельно для мира, измерения и аккаунта хозяина. Путь выводит `/layoutlevel list`. Чтобы изменить исходную разметку вручную, отредактируй объект `settings` нужной зоны и выполни `/layoutlevel reload`. Чтобы изменить спавн в уже сохранённом уровне, отредактируй `Stage/<имя>/spawn.json` на компьютере хозяина и заново призови копию.

### Сохранения в Stage

При первом успешном `/createstage arena` в папке проекта появляются `Stage/arena/stage.nbt` с зонами, состояниями блоков и расстановкой защитников и `Stage/arena/spawn.json` с настройками каждой красной зоны по её ID. Команда захватывает блоки во всей выделенной области и зоны, которые целиком лежат внутри её границы, в том числе зоны, размеченные до создания исходной области. Для защитников сохраняются ID, относительные координаты, направление и тип зоны. Обычные сущности мира, состояние боя, содержимое контейнеров и другие данные блоковых сущностей в сохранение не входят. Для копирования требуется площадка для входа с двумя свободными блоками над ней. Ширина и длина ограничены 128 блоками, общий объём — 262 144 блоками. По высоте размер зависит от измерения.

Следующий `/createstage arena` читает сохранённые блоки, зоны, расстановку и актуальный `spawn.json`. Если хозяин вызывает уровень в измерении его исходной области, мод добавляет недостающие зоны и обновляет сохранённую расстановку. Так можно перенести защитников и в старые сохранения. У каждой красной зоны собственный объект настроек по её ID. Если сохранения и исходной области с таким именем нет, команда сообщает об этом. Готовая копия занимает свободное место у верхнего предела строительства с запасом двух блоков для входа и спавна.

Когда игрок удаляется больше чем на 20 блоков от своей копии, игра предупреждает его. Возврат в этот радиус отменяет отсчёт. Через 10 секунд за его пределами копия убирается автоматически. Команда `/removestagecopy arena` убирает её сразу. В обоих случаях игрок возвращается в исходную точку и измерение, а сохранение остаётся. При закрытии мира копия убирается при следующем входе призвавшего её игрока. Команда `/removestage arena` доступна хозяину и убирает все призванные копии по имени. Расстановка мобов и изменения блоков внутри копии действуют до её удаления или замены. Следующий `/createstage` начинает с сохранённых блоков и расстановки исходной области.

### Игра по LAN

1. Хозяин сохраняет уровень первым вызовом `/createstage arena` и открывает мир по LAN.
2. Каждый подключившийся игрок может ввести `/createstage arena` и получить свою временную копию того же сохранения. Новый вызов заменяет предыдущую копию этого игрока.
3. С Layout Camera на клиенте гость может осматривать зоны и расставлять мобов в своей копии. Внутри неё введи `/givepet <id>`, нажми **J** и перетащи предмет из хотбара на подходящую свободную точку.
4. Для выхода из своей копии игрок может ввести `/removestagecopy arena`. Исходная разметка, редактирование настроек, запуск волн и удаление чужих копий доступны хозяину.

Между ближайшими краями копий разных игроков в одном измерении должно быть не меньше **1000 блоков по горизонтали**. Если подходящего места нет, команда сообщает об этом. Блоки и боевые мобы видны в мире. Границы зон и модели расстановки каждой копии получает только призвавший её игрок.

## Маршрут волны

1. Введи `/giveroutetool` и возьми «Разметчик маршрута» в основную руку. Выйди из режима планирования (**J**).
2. В исходной области нажми **ЛКМ** по верху пола у стыка четырёх блоков внутри красной зоны. Точка привяжется к ближайшему стыку 2×2.
3. Нажимай **ЛКМ** на поворотах. Между точками нужна свободная полоса пола. Для спуска на один блок поставь точки до и после края. **ПКМ** убирает последнюю точку черновика.
4. Поставь последнюю точку внутри белой зоны, чтобы сохранить маршрут (до 128 точек). **ПКМ** на красной зоне без активного черновика показывает её сохранённый путь.

Разметка сохраняется для каждой красной зоны исходной области. Следующий запуск уровня с карты или через `/createstage <имя>` переносит новый маршрут в сохранение и копию. Белый финиш должен быть включён. Для ручного маршрута расстояние до него задают выбранные точки. Для автоматического пути действует `finish_search_radius`.

Без ручной разметки мобы идут по стыкам площадок 2×2, если между красной и белой зонами есть подходящий проход. Для старых площадок с узкими проходами используется навигация Minecraft. В новой копии уровня частицы сразу показывают построенные маршруты. Линия каждой красной зоны исчезает, когда из этой зоны действительно появляется первый моб. Если место спавна занято, линия остаётся видна до успешной попытки.

Если моба столкнули с линии или он сошёл с неё во время боя, он прокладывает путь к финишу от своей текущей позиции. Пройденные точки остаются позади.

## Карта уровней

Открой карту клавишей **K** или нажми **ПКМ** по NPC «Карта уровней», созданному командой `/createlevelnpc`. Уровни показаны карточками, соединёнными линиями по порядку прохождения. Сначала доступна первая карточка. Каждая победа открывает одну следующую карточку, ранее пройденные уровни можно запускать повторно. Если открыто больше шести уровней, между участками карты можно переключаться стрелками.

Карта затемняет и размывает мир на фоне. Сила размытия зависит от настройки размытия меню в Minecraft.

### Как разместить карточки на карте

Открой [campaign.json](config/layout-camera/campaign.json) в папке `%USERPROFILE%\Desktop\Cristnights\config\layout-camera`. Внутри `levels` найди запись нужного уровня и добавь в неё поля `x` и `y`. Например, одинаковое значение `y: 50` поставит две карточки в один ряд посередине карты, а `x: 25` и `x: 75` разнесут их влево и вправо.

```json
{
  "levels": [
    { "stage": "stage_1", "title": "Уровень 1", "x": 25, "y": 50 },
    { "stage": "stage_2", "title": "Уровень 2", "x": 75, "y": 50 }
  ]
}
```

- `levels` — массив карточек в порядке прохождения. Пустой массив оставляет карту пустой.
- `stage` — уникальное имя из `/createstage <имя>`. Уровень загружается из `Stage/<имя>`. Если сохранения ещё нет, хозяин может создать его из одноимённой исходной области.
- `title` — подпись карточки и HUD. По умолчанию используется `stage`.
- `x` и `y` — необязательные координаты центра карточки в процентах от `0` до `100` в пределах рабочей области страницы. У `x` ноль слева, у `y` ноль сверху. Одинаковый `x` выравнивает карточки в столбец, одинаковый `y` — в ряд. Пропущенную координату карта рассчитывает сама для двух параллельных рядов. Порядок прохождения задаёт порядок записей в `levels`.

Сохрани файл и заново открой карту клавишей **K** или через NPC. Так можно проверить положение карточек сразу в игре.

### Запуск и прохождение

Прогресс хранится по имени `stage` отдельно для каждого мира и аккаунта в файле `layoutcamera-campaign-<UUID>.nbt` в папке мира. Карта доступна хозяину встроенного сервера. Гости по LAN могут создавать свои копии через `/createstage`.

Нажатие на карточку сразу создаёт личную временную копию и начинает 10-секундный отсчёт на HUD. В это время можно расставлять защитников. Когда отсчёт заканчивается, мод призывает текущую расстановку и запускает волну во всех включённых красных зонах. Защитники, добавленные во время боя, вступают в него в течение полусекунды, если место свободно. Каждой красной зоне нужен включённый белый финиш в пределах её `finish_search_radius`. После старта HUD показывает прошедшее время, количество живых и ещё не появившихся мобов и сколько мобов дошло до финиша.

- На третьем мобе, добравшемся до белого финиша, волна прекращается и открывается окно «Поражение». **Выход** возвращает в точку запуска. **Рестарт** заново создаёт тот же уровень с исходной расстановкой и новым отсчётом.
- Если волна исчерпана и до финиша дошло меньше трёх мобов, появляется окно «Победа». Прогресс сохраняется, через три секунды игрок автоматически возвращается в точку запуска.

Команда `/startspawn` используется для ручного спавна вне активного испытания.

## Настройки мобов

Над видимыми мобами в мире отображается полоска текущего здоровья. Её длина показывает оставшуюся долю здоровья, а цвет меняется с зелёного на жёлтый и красный по мере урона. Блоки закрывают полоски, а **F1** скрывает их вместе с интерфейсом.

Файл [`config/layout-camera/mobs.json`](config/layout-camera/mobs.json) в папке `Cristnights`. Каждый ключ верхнего уровня — уникальный ID моба. Короткий ID вроде `chicken_bab` означает `layoutcamera:chicken_bab`. Между записями нужна запятая.

| Параметр | Значение |
| --- | --- |
| `model` | Обязательный ID типа моба из Minecraft, например `"minecraft:chicken"`. Определяет модель и базовый тип сущности. |
| `name` | Имя моба и подпись предмета призыва. Без поля используется имя выбранного типа Minecraft. |
| `summon_item` | ID предмета для `/givepet`. По умолчанию `"minecraft:clay_ball"`, глиняный шарик. |
| `health` | Максимальное здоровье в игровых единицах. 2 единицы — одно сердце. Минимум 1. Без поля используется значение модели. |
| `armor` | Значение атрибута брони. Минимум 0. Без поля используется значение модели. |
| `damage` | Урон за удар в бою фракций. Минимум 0. При нуле или отсутствии поля используется положительный базовый урон модели, а если его нет — 2 единицы. |
| `attack_speed` | Число атак в секунду в бою фракций. Минимум 0. При нуле или отсутствии поля используется 1 атака в секунду. |
| `attack_knockback` | Сила отбрасывания цели от прямых ударов, атак по сетке и снарядов, заданных в `mobs.json`. Допустимы числа от 0 до 5, например `0.8`. По умолчанию `0`, при котором цель не отбрасывается. Сопротивление цели к отбрасыванию учитывается. Новое значение применяется при следующем призыве моба или запуске волны. |
| `movement_speed` | Базовое значение атрибута скорости Minecraft при ходьбе и полёте, если у моба есть соответствующий атрибут. Допустимы числа от 0 до 1024, например `0.35`. При `0` скорость этого атрибута равна нулю. Без поля используются обычные значения выбранного типа моба. |
| `can_move` | `true` разрешает обычный ИИ, `false` отключает самостоятельное движение. По умолчанию `true`. Неподвижный защитник может атаковать в пределах досягаемости. Мобы из зоны спавна всегда могут двигаться по маршруту. |
| `can_place` | Разрешает размещение в режиме планирования. По умолчанию `true`. |
| `placement_zone` | Один код зоны, в которой можно разместить моба. По умолчанию `"blue"`. |
| `faction` | `"peaceful"` — мирная фракция, `"hostile"` — злая. Фракции атакуют друг друга. Без поля категория монстров Minecraft считается злой, остальные типы — мирными. |
| `attack_zones` | Список зон, где этот моб может выбирать цели, когда появился в волне. Переопределяет список из `spawn.json`. Например, `["green"]` позволяет атаковать защитников Нижней зоны. `[]` отключает выбор целей в таком бою. |
| `attack_grid` | Сетка атаки защитника, заданная списком строк. Каждая клетка занимает 2×2 блока. Без сетки действует дальность выбранного типа атаки. |
| `attack_block` | Сколько атакующих из волны моб может одновременно сдерживать. Целое число от 0, по умолчанию 1. При `2` двое останавливаются для боя, остальные продолжают путь. При `0` моб никого не задерживает. |
| `attack_type` | `melee` — прямой удар, `ranged` — выстрел по видимой цели в пределах 12 блоков. При отсутствии поля и для старых значений, включая `none`, применяется прежнее поведение моба. |
| `projectile` | Снаряд для `attack_type: ranged`. Допустимы `arrow` (стрела), `snowball` (снежок) и `egg` (яйцо). По умолчанию `arrow`. |
| `mob_type` | Текстовое поле прежнего конфига. Сторону в бою задаёт `faction`. |
| `defense` | Числовое поле прежнего конфига. Урон в бою сейчас рассчитывается с учётом `armor` средствами Minecraft. |

Пример записи защитника. У него 10 сердец здоровья, он размещается в Нижней зоне и сдерживает двух врагов.

```json
{
  "layoutcamera:lower_guard": {
    "model": "minecraft:chicken",
    "name": "Страж Нижней зоны",
    "faction": "peaceful",
    "can_move": false,
    "placement_zone": "green",
    "health": 20,
    "damage": 3,
    "attack_speed": 1,
    "attack_block": 2
  }
}
```

Старый файл `config/layout-camera/mobs/planning_chicken.properties` используется для переноса прежних настроек встроенной курицы и как запасной источник её параметров. В нём `id` обозначает прежний ID курицы. В `mobs.json` ID задаётся ключом записи.

Чтобы изменить скорость, добавь `"movement_speed": 0.35` в запись нужного моба. Новое значение применяется при следующем призыве или запуске волны. Для мобов из красных зон итоговая скорость ходьбы и полёта умножается на 0.5. Для обычного призыва и защитников самостоятельное движение зависит от `can_move`.

### Ближняя и дальняя атаки

Добавь эти поля в запись нужного моба в [mobs.json](config/layout-camera/mobs.json), чтобы он бросал снежки.

```json
{
  "attack_type": "ranged",
  "projectile": "snowball",
  "damage": 3,
  "attack_speed": 2
}
```

Снаряд наносит `damage` при попадании. Если `damage` равно нулю или отсутствует, применяется обычный урон моба или запасное значение 2. Снаряд проходит сквозь союзников, останавливается на блоках и исчезает после попадания. Перечисленные типы применяются к мобам из `mobs.json` после нового призыва или запуска волны. Для прямого удара укажи `"attack_type": "melee"` и убери поле `projectile`.

### Сетка атаки защитника

Добавь поле `attack_grid` внутрь записи нужного моба в [mobs.json](config/layout-camera/mobs.json). Например, эта сетка отмечает три клетки в дальнем ряду и одну прямо перед мобом.

```json
{
  "attack_grid": [
    ".###.",
    "..#..",
    "..M..",
    ".....",
    "....."
  ]
}
```

- `M` — клетка моба в центре. Замени её на `@`, чтобы моб мог атаковать и в центральной клетке.
- `#` отмечает клетку атаки, а `.` оставляет её пустой. Все строки должны быть одинаковой длины. Высота и ширина сетки нечётные, от 1 до 31 клетки.
- Верх массива соответствует направлению взгляда моба. Сетка перемещается и поворачивается вместе с ним. Клетка определяется по горизонтальным координатам ног цели. Она действует и выше, и ниже уровня отрисовки сетки.

В режиме планирования сетка появляется, когда ты перетаскиваешь моба над свободной подходящей точкой. После размещения она скрывается. Нажми **ПКМ** на расставленном защитнике, чтобы показать его сетку и кнопку удаления, в том числе во время боя. Повторное нажатие на того же моба скрывает их.

В обоих случаях клетки атаки показаны полупрозрачными оранжевыми диагональными полосами и контурами. Участки внутри блока поднимаются на его верхнюю поверхность. Открытые участки остаются на исходной высоте. На перепадах между соседними участками полосы продолжаются по вертикальной грани. Препятствия перед сеткой закрывают её так же, как у Верхней зоны.

Защитник с сеткой выбирает видимого противника из волны в отмеченной клетке. При дальней атаке дополнительно действует предел 12 блоков. Параметр `attack_block` задаёт, сколько противников остановится для боя. Сетка действует для расставленных и вызванных защитников. Изменения сетки применяются при следующем призыве защитника или запуске волны.

## Настройки волны

Для зон вне уровней используется [`config/layout-camera/spawn.json`](config/layout-camera/spawn.json) в папке `Cristnights`. Для сохранённого уровня настройки хранятся в `Stage/<имя>/spawn.json`, по отдельной записи на ID каждой красной зоны.

| Параметр | Значение |
| --- | --- |
| `order` | Обязательный непустой список ID в порядке спавна. Можно смешивать типы Minecraft и ID из `mobs.json`. Когда список заканчивается, он повторяется с начала. |
| `interval_ticks` | Положительное целое число тиков между появлениями. 20 тиков — примерно одна секунда. |
| `total_enemies` | Положительное целое число мобов на всю волну суммарно по ближайшим зонам вне уровней. В красной зоне уровня лимит относится только к ней. Ожидание свободного места не расходует лимит. |
| `finish_search_radius` | Радиус поиска ближайшего финиша в блоках. По умолчанию 50. Если подходящих пар спавн–финиш нет, команда показывает ошибку и волна не начинается. |
| `attack_zones` | Общий список разрешённых зон для атакующих из волны. Без поля разрешены все зоны. Если в `mobs.json` у конкретного атакующего задан свой список, применяется он. |

```json
{
  "order": ["minecraft:zombie", "minecraft:skeleton"],
  "interval_ticks": 40,
  "total_enemies": 10,
  "finish_search_radius": 50,
  "attack_zones": ["green"]
}
```

В этом примере зомби и скелеты чередуются каждые две секунды. Они атакуют защитников Нижней зоны, если те впереди, могут сдержать ещё одного противника и их ноги меньше чем на один блок выше ног атакующего. Когда цель погибает или поднимается на один блок и выше, атакующий освобождает место сдерживания и продолжает маршрут. При наступании на финиш моб исчезает.

Общий `spawn.json` читается при `/startspawn` вне уровней. Файл `Stage/<имя>/spawn.json` читается при `/createstage <имя>`. Настройки мобов для волны и защитников загружаются при `/startspawn`. Обычный призыв и новая попытка размещения используют текущий `mobs.json`.

Мобы из зоны спавна передвигаются без подъёма на блоки, наземных прыжков и лазания по лестницам. Прокладывай путь к финишу без подъёмов. Это правило действует и во время боя, и после повторного входа в мир.
